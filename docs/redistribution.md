# Data redistribution policy

Matryoshka distributes nucleotide sequences traceable to public accessions,
the Apache-2.0 PlasmidFinder database, and locally derived short consensus
motifs documented in the reference manifest. Public accession does not itself
override the source database's terms; the manifest therefore records source
terms rather than making a blanket public-domain claim.

Expert feedback and privately supplied working documents were used to define
the ontology and validation assertions, but the original documents are not
part of the public package or test corpus. The software retains source
traceability through publication references, accessions and stable feature
identifiers without redistributing correspondence.

Before adding a new reference, record its accession, coordinates, licence,
provenance, scan thresholds and SHA-256 checksum in
`matryoshka/references/manifest.yaml`.
