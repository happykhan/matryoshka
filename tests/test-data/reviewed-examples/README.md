# Partridge validation sequences

These FASTA fixtures encode the public-accession sequence examples used to
validate the expert-reviewed subset. Their accessions and derivation are
recorded in `matryoshka/references/manifest.yaml` and the component inventory.

The privately supplied Word documents used to interpret these examples are not
redistributed in the public software test corpus. Tests depend only on sequence
fixtures and derived, reviewable assertions. Permission to publish any original
correspondence or working documents must be obtained separately.
