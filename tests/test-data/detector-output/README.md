# Compact detector-output fixtures

These small TSV files are hand-authored parser and rule fixtures, not claims that the
named detector produced a full annotation of the corresponding plasmid. They use real
plasmid identifiers and biologically relevant test coordinates, but contain only the
rows needed to exercise Matryoshka's parsers, hierarchy and inference rules.

The complete public plasmid FASTAs used for sequence-level acceptance checks are in
`../acceptance/`.
