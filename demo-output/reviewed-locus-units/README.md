# Expert-reviewed unit-transposon demonstration

This reproducible six-record demo contains Tn21 (AF071413) plus expert-reviewed
Tn1721, Tn1722, Tn4401, Tn5393 and Tn5403 references.

- `calls.json` is the nested machine-readable annotation.
- `locus-map/` contains one approximately-to-scale locus map per unit.
- `locus-table/` contains the matching Position/Name/FID/Type/Notes locus table.
- `reviewed-units.fasta` is generated by `scripts/make_reviewed_units_demo.py`.

Each map and table now includes its own key. The parent row reports the measured
reference match and boundary evidence; projected internal-map rows explicitly say
that they are curated features from the named reference accession.

The internal maps preserve the expert-reviewed component distinctions. In particular:

- Tn21 contains tnp, IRi, 5'-CS, an aadA1 cassette region, partial 3'-CS,
  partial Tn402 tni, IRt, mer and terminal IRs;
- Tn1721 retains the internal IRR and partial duplication rather than being
  flattened into Tn1722;
- Tn4401 contains exact ISKpn7 and ISKpn6 calls, not family-only labels; and
- complete unit calls override competing terminal fragments.

Minor substitutions and internal insertions/deletions are assembled into one
`Tn*-like` locus. Partial loci retain a fragment label and do not receive a
complete projected internal map.
